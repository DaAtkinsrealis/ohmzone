ohmic (Ω) method, all impedances referred to secondary voltage base
Method notes. This tool sums resistance and reactance vectorially (not just impedance magnitudes) per the guidance in IEEE Std 242 (Buff Book) / IEEE Std 551 (Violet Book) recommended practice for short-circuit calculations in industrial and commercial power systems, then refers upstream impedance to the secondary voltage base using Z₂ = Z₁·(V₂/V₁)². Transformer %Z / X-R defaults are typical values consistent with ANSI/IEEE C57.12.00 and C57.12.26 standard impedance levels and the IEEE 242 suggested X/R table — they are not a specific manufacturer's factory test result; always substitute the nameplate %Z and X/R once a unit is selected (tolerance per ANSI/IEEE C57.12.00 §9 is ±7.5% for two-winding units, ±10% for autotransformers/3-winding units). Cable resistance and reactance values are taken from NEC Chapter 9, Table 9 (600 V cables, 3-phase, 60 Hz, 75°C, three single conductors in conduit) — the CSA C22.1 (Canadian Electrical Code Part I) Appendix D tables follow the same underlying methodology for Canadian installations; consult the applicable table directly for conductor sizes or configurations beyond this reference set. The peak (crest) asymmetrical current factor κ uses the IEC 60909-0 approximation κ = 1.02 + 0.98·e^(−3R/X); ANSI/IEEE C37.010 multiplying-factor tables should be used instead when sizing ANSI-rated switchgear. This tool is for preliminary planning only — a stamped short-circuit / coordination study by a qualified engineer is required before equipment is specified or purchased.
