Screening-level assessment only. This tool performs a simplified, single-frequency-per-order emission and voltage-distortion estimate using the CSA C61000-3-6 harmonic summation law and a linear (X = hX₁) system impedance model. It is not a substitute for the network harmonic impedance data, background distortion measurements, and detailed frequency-scan study that Hydro-Québec requires for an actual compliance submission — and it does not replace the specific per-harmonic limit tables that HQ or the applicable CSA standard provides for your point of connection. Default limit values shown are commonly published representative figures and must be replaced with the actual values issued for your project before this is used for compliance purposes.
